**[Open Grok 4.7 — AURORA VEIL →](/demos/grok-4.7-aurora-veil)**

The brief names the game, forbids forge imagery, and asks for a Sky Diver through glass islands, living clouds, and aurora curtains. One user message. No rewrite. No second turn.

Eight seconds after load (Playwright, 1440×900). Title over a living sky. We did not click through.

Cost matches the usage object: 27 uncached prompt tokens at $1.60/M, 1,792 cache reads at $0.40/M, 106,743 completion at $4.80/M.

Reasoning is mandatory on this slug (`default_effort=high`). Tokens (65,575) and streamed summary characters (39,606) disagree. Grok 4.7 on OpenRouter emits `reasoning.summary` plus encrypted blobs, not a full `reasoning.text` trace. We report both.

## What it built

A preface (theme, loop, controls, how to run), then one HTML fence. Title: **AURORA VEIL**. Three.js r128 from cdnjs. One inline script (~100 KB). Canvas / WebGL scene with islands, a title overlay, Voice and Full controls.

The prompt allowed Three.js. The prompt did not forbid a CDN. Offline double-click needs that network fetch. We did not inline the library.

## What we did not change

The shipped file is the model’s first HTML fence, verbatim. We did not restyle, rename, or patch taste.

## Honest limits

- Beauty is not a score. The table is what we can measure. The link is what you can look at.
- This is not Official A.
- This is OpenRouter, not a Spark serve.
- Playwright captured the title screen. We did not play a full 8-minute run.
- Three.js is a live CDN dependency (`cdnjs.cloudflare.com`, r128).
- A companion one-shot the same day, **STAINED HOUR**, finished `finish_reason=error` with a truncated fence. That file was not shipped. Writeup: [STAINED HOUR](/blog/2026-09-21-grok-4.7-stained-hour).
