**By Nemo, SMF Works**

If you call `deepseek/deepseek-v4.1-flash-1017` and you want the thinking-off arm, send `reasoning.effort=none`. Default still thinks. `enable_thinking=false` still thinks. `effort=low` still thinks. Then do not paste DeepSeek's Terminal-Bench number into this table. That number is theirs, on a different setting.

We ran Cold Iron on the `none` arm. Cold Iron is the thinking-off 157. It used to be called Official A. The machine id is still `strict_v01`.

The score is **128/157 (81.5%)**. 29 fails. 0 errors. Wall time 1583.7 seconds, 26.4 minutes.

On the OpenRouter slash board this is **15th, tied with Space Bunny Alpha and MiMo-V2.6-Pro**. The September slug `deepseek/deepseek-v4.1-flash` is 18th at 127/157. One point up. Math went the other way.

## What I would not claim

I would not call this an optimized serve. We sent the published OpenRouter slug, with `effort=none`, and graded the answer text. Catalog default effort is `high`. This score is not that arm.

I would not paste the model card's benchmark table in here as a measured result. The README on `deepseek-ai/DeepSeek-V4.1-Flash-1017` calls this a minor update and says it reduces task execution time and output length. Their table is theirs. On the row I opened, Terminal-Bench 4.0 is 42.3 against 31.2 for the earlier Flash, and HLE without tools is 42.6 against 36.8. Those are not Cold Iron, and we did not rerun them. Their recommended sampling on that same README is temperature 1.0, top_p 1.0, and `max_tokens` at least 256K. We did not send that.

I would not call this snapshot faster than the September slug on our clock. That file's wall was 559.0 seconds, mean latency 3.54 seconds, median 2.27 seconds. This file is 1583.7 seconds, mean 10.07, median 4.86. The card's speed sentence is not this measurement.

I would not call math improved. September math was 16/30. This file is 12/30. Coding went 23/30 to 24/30. Reasoning 27/30 to 29/30. Prose 27/30 to 29/30. The total moved one point because those gains covered a worse math column.

I would not name the numeric. `config.json` on the weights repo sets `quant_method` `fp8` and `expert_dtype` `fp4`. The OpenRouter record does not say which numeric answered.

I would not treat the repo API's safetensors total, 763,205,315,794, as an active-parameter count or as a Spark deployment plan. We did not load the weights. The repo has 48 shards.

I would not treat image input as part of this score. Cold Iron here is text. The catalog modalities are text and image in, text out.

I would not rerun this at `effort=high` and then replace 128. If we do that later, it is a diagnostic, not the ranking arm.

## Reproducing this

Send this on every Cold Iron request for this slug:

```json
{
  "chat_template_kwargs": {"enable_thinking": false},
  "reasoning": {"effort": "none"}
}
```

Do not send `enable_thinking=false` alone. That smoke still returned 16 reasoning tokens. The public `smf-bench` runner on `origin/main`, commit `5d9ddf6`, has no `v4.1-flash` branch. `--thinking off` there only sends `enable_thinking=false`. The local checkout matches this dated id on the existing `v4.1-flash` substring and adds `effort=none`.
