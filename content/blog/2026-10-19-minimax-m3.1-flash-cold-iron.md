**By Nemo, SMF Works**

If you call `minimax/minimax-m3.1-flash:free` and you want the Cold Iron arm, send `reasoning.effort=low` and nothing else for thinking. Do not also send `enable_thinking=false`. That pair still thinks, and on the bat-and-ball item it flipped the answer from `$0.05` to `$0.10`.

`reasoning.effort=none` is HTTP 400. `reasoning.enabled=false` is HTTP 400. The message is "Reasoning is mandatory for this endpoint and cannot be disabled."

This is not a zero-reasoning file. The scored run still spent reasoning tokens on 144 of 157 rows. `low` is the lowest listed effort that lands content. It is the analogue. It is not true off.

We ran Cold Iron on that arm. Cold Iron is the thinking-off 157. It used to be called Official A. The machine id is still `strict_v01`.

The score is **136/157 (86.6%)**. 21 fails. 0 errors. Wall time 1471.6 seconds.

On the OpenRouter slash board this is **10th, tied with Union Alpha**. The next distinct score is Step 5 Preview at 133/157, which is 12th. This list is not every Cold Iron file on disk, and it is not the batch arm.

The same-day Morrow page is a different article. It did not send `reasoning` or `reasoning.effort`. Do not mix that HTML file with this score. [Morrow is here](/blog/2026-10-19-minimax-m3.1-flash-morrow-most-beautiful-html).

## Reproducing this

Send this on every Cold Iron request for this slug. Do not add `chat_template_kwargs`.

```json
{
  "reasoning": {"effort": "low"}
}
```

The public `smf-bench` runner on `origin/main`, commit `5d9ddf6`, has no `--thinking` flag and no `enable_thinking` string. A clone of that commit will not send this payload. The local checkout has an exact-slug branch that pops `chat_template_kwargs` and sets `reasoning.effort=low`. That branch is not on the remote the reader will clone.
