Grok 4.7 dropped. Michael asked for the same one-shot craft test we ran on Grok 4.6: `x-ai/grok-4.7` on OpenRouter, the empty 13-word brief, no rewrite, no second turn, ship the fence.

The prompt, verbatim:

> create the most beautiful and stunning single HTML file you can possibly imagine

**[Open Grok 4.7 — AETHER →](/demos/grok-4.7-aether)**

Prior pieces, still live: **[AURELIA](/demos/ox-alpha-aurelia)** · **[Grok 4.6 AETHER](/demos/grok-4.6-aether)** · **[SUMI](/demos/glm-5.3-flash-sumi)** · **[Hy4 LUMEN](/demos/hy4-preview-lumen)** · **[ELSEWHERE](/demos/gpt-6-astra-pro-elsewhere)** · **[DeepSeek LUMEN](/demos/deepseek-v4.1-flash-lumen)** · writeup [One prompt, two pages](/blog/2026-08-25-ox-alpha-vs-grok-4.6-most-beautiful-html).

It named the page **AETHER — Sanctuary of Light**. Grok 4.6 already used AETHER for [the observatory](/demos/grok-4.6-aether). We did not rename either. The live paths differ.

Five seconds after load (Playwright, 1440×900). Type and chrome first; the field is already lined.

Cost matches the usage object at list rates with 128 cached prompt tokens: (92 × $1.60 + 128 × $0.40 + 7,376 × $4.80) / 1M = $0.0356032.

The prompt file is still 81 bytes. Grok 4.6 on the same prompt used 220 prompt tokens too. We report the usage object.

Reasoning tokens (314) and streamed summary characters (203) disagree because Grok 4.7 on OpenRouter emits `reasoning.summary` plus `reasoning.encrypted`, not a full `reasoning.text` trace. We report both.

## How Grok 4.7 handled it

The brief is still empty. Grok 4.6 built a scrollable *page* (AETHER the observatory). Grok 4.7 built another *page*, closer to a night HUD than a manifesto: canvas ribbons, two diegetic cards, two buttons, a clock.

The visible reply is a one-line preface, then a single HTML fence. Title: **AETHER — Sanctuary of Light**. Hero: “Stillness, illuminated.” One inline script. Canvas 2D, no Three.js, no WebGL, no Google Fonts, no picsum.

2. `include_reasoning` off, id `gen-1790011624-qmveITDANyc6dmuv8KeQ`: **5.16 s**, **155** content chars, $0.0012784. A description, no fence.

The shipped file is call 3. Reasoning is mandatory on this slug either way; turning the flag off only hid the summary.

## What we did not change

The shipped file is the model’s first HTML fence, verbatim. We did not restyle, rename, or patch taste.

No Google Fonts. No picsum. Offline double-click has a system stack.

## Honest limits

- One open-ended prompt. Beauty is not a score. The table is what we can measure. The link is what you can look at.
- This is not Official A. It does not replace a 157-test score.
- This is OpenRouter, not a Spark serve.
- Playwright captured the first viewport after 5 s. We did not click **ENTER THE VEIL** or **SHIFT THE SKY**.
- Two prior calls on this slug failed to emit a complete fence. They are not this page.
