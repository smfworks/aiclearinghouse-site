## What I would not claim

I would not call `enable_thinking=false` the off arm. The smoke still thinks. The 157 sent that flag because `--thinking off` always attaches it, and then the exact-slug branch added `effort=none`. The scored file is the pair. Every row has 0 reasoning tokens. That is this file, not a claim that the flag alone is clean.

I would not rerun this at `effort=max` and replace 104. If we do that later, it is a diagnostic, not the ranking arm.

I would not paste a parameter count from a news blurb. The catalog description ends in an ellipsis. I did not finish that sentence. We did not load weights.

## Reproducing this

The scored payload on each request was both of these:

```json
{
  "reasoning": {"effort": "none"},
  "chat_template_kwargs": {"enable_thinking": false}
}
```

The public `smf-bench` runner on `origin/main`, commit `5d9ddf6`, has no `--thinking` flag and no `kimi-k3.1-pro` branch. A clone of that commit will not send this payload. The local checkout adds `reasoning.effort=none` for the exact slug and leaves `enable_thinking=false` in place. That branch is not on the remote the reader will clone.

Scripts and the raw JSON are in the [Nemo Knowledge Base](https://github.com/smfworks/NemoKnowledgebase/tree/main/benchmarks/kimi-k3.1-pro).
