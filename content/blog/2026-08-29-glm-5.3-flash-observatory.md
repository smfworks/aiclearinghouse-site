## How GLM handled it

It built an ops wall, not a chart demo.

Playwright Chromium, 1440×900, 4 s after `networkidle`. Zero `pageerror`. Zero console.

![Observatory still, 1440×900](/images/blog/2026-08-29-glm-5.3-flash-observatory-screenshot.png)

What is on screen:

- Top bar: `SPARK-PAIR / GLM-5.3-FLASH`, chips `320B-A18B MoE`, `KDA + MLA hybrid`, `native multimodal`, `CTX 262,144`, UTC clock `18:12:20`, health pill `NOMINAL`, shift toggles Daylight / Combat Red / Diagnostic, `REPLAY 60 s`.
- Left: SPARK-A and SPARK-B cards. Temps 60.9°C / 61.7°C, mem ~107 GiB, decode 69 / 66 tok/s, prefill 4.6k / 4.3k, power 98 / 95 W, fan, NVLink, RoCE 24.4 GB/s. Temps sit together; clocks both 1007 MHz.
- Center: REQUEST RIVER with lane counts (coding 2, agent 5, vision 0, long-ctx 6) and moving pills. In-flight 2, queue 0.
- Right: KV-cache stacked area (40.4 / 80 GiB), concurrency × TTFT scatter (n=420, median 1.6 s), expert-routing heatmap `8 / 288 PER TOKEN`.
- Bottom event log with four UTC lines. Footer: `SIMULATION — not reading real node metrics unless wired later.` Seed `0x5f3759df`.

That is the brief’s layout. It is also crowded at 1440.

Concrete defects in the still:

1. Request river is mostly empty dark field; pills clip (`AGEN` truncated, `182D 8.` cut at the right edge).
2. Node sparklines have overlapping labels (`dec pre own scale` unreadable).
3. Vision lane is empty (count 0) — legal for a quiet moment, but the river then looks unfinished.
4. Concurrency scatter is a vertical strip of dots, not a cloud — encoding is weak.
5. Drawer panel at the far bottom (`ARRIVED / TOKENS IN / …`) is empty dashes until a pill is clicked.
6. IBM Plex via Google Fonts; fail closed.

We did not taste-edit. Test 8 is the inspect/refine loop.

## What we did not change

Prompt verbatim. First HTML fence, shipped. The model stopped on its own at 62,935 completion tokens.

## Honest limits

- Numbers are simulated. The footer says so. We did not wire `:8888/metrics`.
- Playwright software canvas. No FPS claim (`render ≈30 fps` is the page’s own caption).
- DFlash2 draft weights on this recipe are CC BY-NC-ND. Research/eval window.
- Hermes provider pins for `:8888` lag. We report `/v1/models` and the completion `model` field.
