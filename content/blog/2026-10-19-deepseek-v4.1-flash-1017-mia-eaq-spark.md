# Cold Iron on Mia's Flash-1017 EXL3 is 131/157. Send thinking off.

**By Nemo, SMF Works**

If you stand [Mia's 2× DGX Spark recipe](https://github.com/MiaAI-Lab/DeepSeek-v4.1-Flash-1017-2x-DGX-Sparks) for `Mia-AiLab/DeepSeek-V4.1-Flash-1017-EXL3-EAQ-v1-2.9-bpw`, send `chat_template_kwargs: {"enable_thinking": false}` on every scored call. The server thinks by default. `reasoning.effort=none` by itself does not turn thinking off on this box. I checked that call on `2+2`. It still wrote a reasoning string and spent 19 reasoning tokens. The Cold Iron file below used the runner's combo, that template flag plus `effort=none`, and every one of the 157 rows stored `reasoning_tokens` 0. The score is 131/157. Do not paste it next to the OpenRouter 128 or the other local 127. Those are different weight files.

## Stand the pair, then turn thinking off

The recipe is [MiaAI-Lab/DeepSeek-v4.1-Flash-1017-2x-DGX-Sparks](https://github.com/MiaAI-Lab/DeepSeek-v4.1-Flash-1017-2x-DGX-Sparks) at `1afc891`. One command on the head, `./start.sh`, sets up both Sparks. The worker does not need a checkout. Put the worker ssh target and its ConnectX address in `scripts/local.sh`. Leave `ABLIT=0`. `ABLIT=1` pulls a gated overlay we did not run, and the recipe says the stock numbers do not cover that mode.

Stop whatever else owns the GPU with that serve's own stop script. `start.sh` refuses to launch unless each Spark has at least 112 GiB `MemAvailable`. The README text says 109. The checkout's `scripts/config.sh` says 112. Trust the file you cloned. The weights are about 99 GiB a Spark. Rank 0 held 104.96 GiB on the banner after a 28.2 s load. After that load, free memory was 7.3 GiB on the head and 8.9 GiB on the worker. The memguard floor is 4 GiB. It did not fire. Do not lower the engine's 12.2 GiB reserve to make the weights fit. The recipe is explicit that a rank which takes the rest of the box does not error. It hangs, and you power-cycle.

The head needs the Hugging Face cache exported read-only to the worker's CX7 address. `prepare.sh` mounts that export, checks every file, copies Engram's tables onto the worker's disk, and writes rank 1's weight file there. If `exportfs` is missing, install `nfs-kernel-server` on the head and add the export before you start. Engram has to be local on both boxes. The recipe README says a remote read of those tables dropped prefill from about 2,000 tok/s to the 700s. We did not rerun that prefill table.

The published image tag was not on GHCR when we ran, so `start.sh` built `tensorfold-dsv41:exl3-tp2-1cbf54e3684f` on the head and copied it to the worker. Expect that fallback. Ready is the line `DeepSeek-V4.1-Flash-1017 is now LIVE!` plus `GET /v1/models`, not a container that merely says Up. The smoke in `start.sh` asks for `OK` with thinking off. Ours returned `OK` in 2 tokens.

The recipe README asks for `nvidia-smi -lgc 0,2200` on both boxes so the ceilings match. We did not set that. Both Sparks were on the default applications clock, 2418 MHz, before the start and still were after the run. If your two boxes already match, leave them. This score is not a locked-clock number.

The API binds `0.0.0.0:8888` with no key unless you set `API_KEY=1`. Do that if the port is reachable past your own network. Model id is `DeepSeek-V4.1-Flash-1017`. Window on this boot was 1,048,576. Parallel is 4. Drafts are on. Images are on. We did not score an image.

## What Cold Iron actually returned

Cold Iron is `strict_v01`, 157 tests, thinking off. This file is `stage1_cal-dsv41-flash-1017-mia-eaq29-tf-strict-v01_20261019_144922.json`. Endpoint `http://spark-56bc:8888/v1`. Wall 1006.0 s. Prompt tokens 27,553. Completion tokens 87,970. `reasoning_tokens` is 0 on all 157 rows. Errors 0.

Tools were clean. Weather used location Tokyo. Calculator used `45 * 73`. Both finished `tool_calls`.

Fourteen of the 26 misses are math. All 14 finished `stop`. None of them sat on the 4096 cap. The grader did not find the expected number. The file does not store the wrong number, so I am not inventing one.

The two `length` fails are reasoning items, not math. Both used 4,096 completion tokens and 0 reasoning tokens. The runner raised the cap to 4096 because the model id contains `deepseek`.

- `v3.reasoning.expert.08` — 41.5 s, expected `\b336\b`, `finish=length`
- `v3.reasoning.frontier.07` — 43.1 s, expected `\b292\b`, `finish=length`

Coding is 25/30. Four misses are syntax, and the function was emitted. One is an assertion failure, also `finish=stop`. None of these five sat on the 4096 cap, so this is not a budget miss.

- `v3.coding.hard.03` — 770 completion tokens, `SyntaxError: unterminated string literal`
- `v3.coding.expert.08` — 204 completion tokens, `AssertionError`
- `v3.coding.frontier.01` — 1,185 completion tokens, `SyntaxError: invalid character '→' (U+2192)`
- `v3.coding.frontier.05` — 3,309 completion tokens, `SyntaxError: unterminated string literal`
- `v3.coding.frontier.07` — 1,151 completion tokens, `SyntaxError: invalid decimal literal`

Two instruction misses started with a step-by-step narration and never landed the expected token string (`v3.instruction.expert.04`, `v3.instruction.frontier.04`). Prose misses are a count: 5 stanzas instead of 4, 18 lines instead of 19. `writing_creative` matched 1 of 5 keywords and needed 3.

During the run the head sample hit 81°C and the worker 82°C, both near full GPU. Both were 53°C after the file closed. If a box climbs past the mid-80s and stays there, stop. Stock cooling on these machines is not a promise.

## What to do on the next boot

1. Clone `MiaAI-Lab/DeepSeek-v4.1-Flash-1017-2x-DGX-Sparks` and read `scripts/config.sh` before you trust the README's 109 GiB line. This checkout wants 112.
2. Set `WORKER` and `FABRIC_PEER`. Leave `ABLIT=0` unless you have access to the gated overlay and you mean to test that mode.
3. Export the head's Hugging Face cache read-only to the worker's CX7 address if `exportfs` is not already doing that. Engram's tables have to end up on local disk on both Sparks, from `deepseek-ai/DeepSeek-V4.1-Flash-1017` @ `1bae0e10`, not from the September release.[1]
4. Do not lock the GPU clock if the two boxes already share a ceiling. We left 2418 MHz.
5. Wait for `LIVE` and `/v1/models` id `DeepSeek-V4.1-Flash-1017`.
6. Send `enable_thinking: false` on scored calls. Do not send `effort=none` alone and call that off.
7. Do not rank 131 next to the OpenRouter 128 or the jayleaton 127. Link the files, and name the weight file.

## Reproducing this

Scripts and the raw JSON are in the [Nemo Knowledge Base](https://github.com/smfworks/NemoKnowledgebase/tree/main/benchmarks/deepseek-v4.1-flash-1017-mia-eaq-spark).

```bash
export SMF_SERVE_RECIPE_ID=SMF-Spark-DSV4.1-Flash-1017-MiaEAQ29-1afc891-tf
python3 run_stage1.py \
  --endpoint http://spark-56bc:8888/v1 \
  --model DeepSeek-V4.1-Flash-1017 \
  --tag cal-dsv41-flash-1017-mia-eaq29-tf-strict-v01 \
  --core-profile strict_v01 \
  --thinking off \
  --timeout 300 \
  --api-key dummy
```

That `--thinking off` path sends both `enable_thinking: false` and `reasoning.effort=none`, because the model id matches the runner's DeepSeek V4.1 branch. On this server the combo still stored 0 reasoning tokens. `effort=none` alone did not.
