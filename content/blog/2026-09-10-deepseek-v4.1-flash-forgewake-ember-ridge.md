## How V4.1 Flash handled it

The brief asked for Canvas 2D only, zero URLs, AUTO on boot, a scripted first eight seconds, and a drawn runner rather than a box.

The visible reply opens with one sentence of preface, then a single HTML fence, then a short controls note. The brief said no prose before or after the fence. We still shipped the fence, not the preface.

It named the page **FORGEWAKE: EMBER RIDGE**. One canvas `#game`. One IIFE script. Named objects for Input, Audio, Particles, Camera, Player, World, Enemies, Autoplay, HUD, and Game. No `http://` strings. No `TODO` / `FIXME`. No `eval`. No `getImageData`. No WebGL. `node --check` on the 90,817-byte script exits 0.

What the 5 s still actually shows: a gold-white stick runner with a cape and blade, magma, two red crawlers, a cyan shard, RECORD letterbox, AUTO pill. Palette is the locked set. It is a playable-looking AUTO scene. It is not a cinematic trailer.

A separate 20 s Playwright load (new seed, 0 console errors, 0 `pageerror`) still showed AUTO, five HP pips, no GAME OVER card, and **6m 20.0s**. The runner was still on the opening ridge, left of the magma shaft. We did not verify the brief’s “AUTO on the shown seed must be survivable for at least 45 seconds,” and we did not verify that AUTO clears gaps. Timer advanced. Distance on the HUD stayed at 6m across the 5 s, 8 s, and 20 s boots we captured.

Line count is **2,896**. The brief asked for 900–1600. We did not cut it.

## What we did not change

The shipped file is the model’s first HTML fence, verbatim. We did not restyle, rename, trim the line count, or patch AUTO.

No Google Fonts. No picsum. No `http://` strings. Offline double-click still has a system stack.

## Honest limits

- One game brief. Playability is not a score. The table is what we can measure. The link is what you can look at.
- This is not Official A. It does not replace a 157-test score. The same-day Official A post is a different artifact.
- This is OpenRouter, not a Spark serve. We did not load `deepseek-ai/DeepSeek-V4.1-Flash` here.
- Playwright captured the first viewport after 5 s. We did not press A, jump, or play MANUAL.
- AUTO at 20 s: no console errors, no GAME OVER, HP still five pips, distance HUD still **6m**. That is not a 45 s survival proof.
- Preface + trailing notes around the fence, against the brief’s “Return ONLY one markdown code block.”
- 2,896 lines vs a 900–1600 target.
- Beauty / “cinematic trailer” is a judgment. The still is a stick runner on a dark ridge.
