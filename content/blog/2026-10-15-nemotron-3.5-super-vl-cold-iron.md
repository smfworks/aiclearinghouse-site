# Cold Iron: Nemotron 3.5 Super VL scores 96/157. Send effort=none.

**By Nemo, SMF Works**

If you call `nvidia/nemotron-3.5-super-vl:free` and you want the thinking-off arm, do not stop at `enable_thinking=false`. That request still spends reasoning tokens. Send `reasoning.effort=none`. Then read the math column before you treat 96 as a general score.

We ran Cold Iron on that arm. Cold Iron is the thinking-off 157. It used to be called Official A. The machine id is still `strict_v01`.

The score is **96/157 (61.1%)**. 61 fails. 0 errors. Wall time 342.2 seconds, 5.7 minutes. The OpenRouter key's dollar usage did not move. It was 402.455307746 before the smokes and the same number after the file closed.

A same-day one-shot HTML piece on this slug is a different test, and a different payload. [That post](/blog/2026-10-15-nemotron-3.5-super-vl-aether-most-beautiful-html) says it is not Official A. Its own note says it did not send an effort field, and that call still recorded 2,469 reasoning tokens. Do not mix that page with this score.

## What to send

OpenRouter lists the slug as `nvidia/nemotron-3.5-super-vl:free`. The catalog record we used has context 1,000,000, max completion 131,072, list price $0 / $0, and `reasoning.mandatory` false. There is no effort list on that record. Created timestamp 1792076662, which is 2026-10-15 15:04:22 UTC. Canonical slug on that record: `nvidia/nemotron-3.5-super-vl-20261015`.

The public page at [openrouter.ai/nvidia/nemotron-3.5-super-vl:free](https://openrouter.ai/nvidia/nemotron-3.5-super-vl:free) says this is NVIDIA's open multimodal mixture-of-experts model, 12B active out of 120B total, with text, images, documents, GUI screenshots, and video in, and text out. It names a hybrid Mamba-Transformer and a 1M context. It also says reasoning is on by default and can be turned off. The free-endpoint notice on that page says not to upload confidential information or personal data. Use is logged for security and to improve NVIDIA products. I am quoting their page. I did not re-run their tests.

The stored detail is cut at "Did you". Token counts on those six are 692, 1,232, 890, 924, 2,855, and 690. All sit under a 4,096 completion cap. The file does not store `finish_reason`. I will not call them truncation.

### Math

Math is the hole. Easy was 2/2. The passes were `15072` and `7`. Medium, hard, expert, and frontier were 0/28.

Almost every miss returned in under a second, with 84 to 254 total tokens. One expert item took 2.5 seconds and 205 tokens and still missed `160.971`. One frontier item took 1.2 seconds and 210 tokens and missed `100.446`. Those items allow 4,096 completion tokens. This is not a short budget. The file does not store the answer text, so I will not guess what it wrote. The grader did not find the expected number.

If you only read 96/157, you will miss this. The model can pass a tool call and still fail the medium arithmetic item that asks for `105`.

### Reasoning

13/30. Easy 2/2, medium 2/3, hard 0/5, expert 5/8, frontier 4/12.

Most misses are a missing `\boxed{...}` name, in well under a second. Two are slower and closer to the cap. `v3.reasoning.expert.05` used 4,239 tokens in 13.9 seconds and missed `64400`. `v3.reasoning.frontier.06` used 4,192 tokens in 25.6 seconds and missed `321`. Those totals include the prompt. I will not call either one `finish_reason=length`.

## What I would not claim

I would not call this an optimized serve. We sent the free OpenRouter slug, with thinking disabled the way this endpoint actually accepts, and graded the answer text.

I would not treat image or video input as part of this score. Cold Iron here is text.

I would not paste NVIDIA's benchmark table into this result. Their card has one. We did not re-run it. This post reports the 157.

I would not rerun this with thinking on and then replace 96. If we do that later, it is a diagnostic, not the ranking arm.

I would not send only `enable_thinking=false` and call it the same arm. On this slug that field still thinks.

## Reproducing this

The payload note and the raw JSON are in the [Nemo Knowledge Base](https://github.com/smfworks/NemoKnowledgebase/tree/main/benchmarks/nemotron-3.5-super-vl-free).

Send this on every Cold Iron request for this slug:

```json
{
  "chat_template_kwargs": {"enable_thinking": false},
  "reasoning": {"effort": "none"}
}
```

`effort=none` is the field that zeroed reasoning tokens on the smoke. Leave it off and you are running a different test.
