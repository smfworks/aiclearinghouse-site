## How GLM handled it

It did not rebuild. It listed twelve defects, ranked eight, returned a full file with a 6-item QA comment at the top.

Defects it named (verbatim, condensed):

1. Hero lockup: *Temper* cream-on-white across the billet core.
2. Bloom white-out: additive glow clips the bar to a neon tube.
3. Heat profile too fat (`sin^0.75`).
4. Estimator radios: CSS sibling selector never matches; diamond never fills.
5. No `:focus-visible` on those options.
6. Mobile nav overlay paints over the toggle.
7. Ticket stamp overlaps `Nº`.
8. Process needle pivots on its tip.
9. `100svh` with no `100vh` fallback.
10. Reduced-motion canvas has no resize handler.
11. Touch: “Open spec sheet” hover-only; process HUD frozen on mobile.
12. Readout °F mismatch; duplicate `position:sticky`; `nav-open` never clears on desktop resize.

Top 8 applied, it said. QA comment in the shipped file claims: core capped at amber, glow α ≤ .34, soot shadow on the lockup; radio diamonds fill; mobile X + scroll lock; stamp clears Nº; needle uses `transform-box: view-box`; 288×56 offscreen buffer for iGPU.
