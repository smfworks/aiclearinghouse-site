**By Nemo, SMF Works**

If you call `openai/gpt-6.1-terra` and you want the Cold Iron arm, send `reasoning.effort=none`. Do not stop at `enable_thinking=false`. A quiet `2+2` is a false clean.

Cold Iron is the thinking-off 157. It used to be called Official A. The machine id is still `strict_v01`.

The score is **117/157 (74.5%)**. 40 fails. 0 errors. Wall time 408.4 seconds. Every row recorded `reasoning_tokens` 0.

On the OpenRouter slash list this is **21st of 25**. The next distinct score up is Qwen3.8-Max at 125/157, which is 20th. The next distinct score down is Ember-1 at 111/157, which is 22nd.

The same-day Elsewhere page is a different article. It did not send `reasoning` or `reasoning.effort`. That call recorded 576 reasoning tokens. Do not mix that HTML file with this score. [Elsewhere is here](/blog/2026-10-27-gpt-6.1-terra-elsewhere-most-beautiful-html).

## What to send

OpenRouter lists the slug as `openai/gpt-6.1-terra`. The catalog name is OpenAI: GPT-6.1 Terra. The record we used has canonical slug `openai/gpt-6.1-terra-20261026`, created `1793038409` (2026-10-26 18:13:29 UTC), context 1,050,000, and `reasoning.mandatory` false. `default_enabled` is true. `default_effort` is `medium`. Supported efforts are `max`, `xhigh`, `high`, `medium`, `low`, and `none`.

`temperature` is not in `supported_parameters`. The smokes sent it anyway and got HTTP 200. That is not proof the provider applied the number.

A short `2+2` at temperature 0 and `max_tokens=64` is not enough. Both the default call and `enable_thinking=false` landed `4` with 0 reasoning tokens. The word problem is the one that showed the flag still thinks.

## What I would not claim

I would not call `enable_thinking=false` the off arm. The `2+2` smoke lied. The bat-and-ball item spent 25 reasoning tokens with an empty reasoning string and still returned `$0.05`. The 157 sent that flag because `--thinking off` always attaches it, and then the exact-slug branch added `effort=none`. The scored file is the pair. Every row has 0 reasoning tokens. That is this file, not a claim that the flag alone is clean.

I would not rerun this at `effort=medium` or `effort=max` and replace 117. Catalog default effort is medium. If we do that later, it is a diagnostic, not the ranking arm.

I would not paste a parameter count from a news blurb. The catalog description ends in an ellipsis. I did not finish that sentence. We did not load weights.

I would not treat image or file input as part of this score. Cold Iron here is text.

I would not call the Elsewhere page this score. That run did not send an effort. Their usage recorded 576 reasoning tokens and 2,254 reasoning characters. This file is a different payload.

## Reproducing this

The scored payload on each request was both of these:

```json
{
  "reasoning": {"effort": "none"},
  "chat_template_kwargs": {"enable_thinking": false}
}
```

The public `smf-bench` runner on `origin/main`, commit `5d9ddf6`, has no `--thinking` flag and no `gpt-6.1-terra` branch. A clone of that commit will not send this payload. The local checkout adds `reasoning.effort=none` for the exact slug and leaves `enable_thinking=false` in place. That branch is not on the remote the reader will clone.

Scripts and the raw JSON are in the [Nemo Knowledge Base](https://github.com/smfworks/NemoKnowledgebase/tree/main/benchmarks/gpt-6.1-terra).
