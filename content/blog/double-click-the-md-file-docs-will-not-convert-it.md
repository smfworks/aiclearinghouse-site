If the draft is already a `.md` file, do not import it into a Google Doc. Open the file. Leave the extension.

On 5 October 2026, the Google Workspace team said it is introducing a way to view, edit, and collaborate on Markdown files directly in Google Docs, and to view a rendered preview in Google Drive. The extensions on that post are `.md` and `.markdown`. The handoff line is the one about file type. People can open, edit, and collaborate on those files without changing it.[1]

That is the review path for a model draft. Google's post says Markdown is the text format large language models already use when they need to keep structure: tables, headers, and bulleted lists, without the bulk of a heavy file. The old move was to import that file and turn it into a Doc. The same post says the conversion often altered formatting, stripped comments, and fragmented files.[1]

You can skip that conversion when the new editor is in the account. Upload the file. Click it twice. Comment in Docs. The file you hand back is still Markdown.

I fetched the Workspace post and both help pages on the morning of 6 October 2026. I did not open a shared draft, and I did not run an agent through the editor. The steps below are the clicks those pages name. If a menu is missing in your account, that is the rollout, not a step I left out.

## Two pages, two jobs

Google still publishes an older help page, "Use Markdown in Google Docs, Slides, & Drawings." I fetched it so the clicks would not get mixed.

That page is a typing aid inside a Doc, plus a set of conversions. On a computer, you open a Doc, a Slides file, or a Drawing, then go to Tools, Preferences, and check or uncheck "Enable Markdown." From there you can paste Markdown and have Docs convert the clipboard into Docs content. You can select a passage, right-click, and choose Copy as Markdown. You can also download the Doc as a `.md` file: File, Download, Markdown (.md).[3]

The import is on that same page, and it is the path to avoid when the deliverable is the Markdown file. Inside Docs: File, Open, Upload, then select the Markdown file. The page says the file is uploaded and opens automatically. In Drive: upload the Markdown file, right-click it, then Open with, Google Docs.[3] Both of those create a Doc from the file. That was the old handoff. It is still documented. It is the wrong click if the brief says the file type stays `.md`.

Keep the older page if you want a Doc, or if you want to export a Doc you already have. Close it if you want the model draft to remain the file under review.

The new help page is the one the 5 October post links. Its important line is plain. "Your file does not convert to a Google Docs file. It stays an .md file, kept in Drive." Docs is the editor, where you see the final format and work with other people. Drive holds the file.[2]

## Read it in Drive before anyone comments

If someone only needs to read the draft, you do not have to open the editor.

The help page's preview path is a right-click.

- Open Google Drive and right-click the file.
- Select Open with, and then Preview.
- At the top of the viewer, switch between Markdown and Preview.
- When you are ready to edit, open the file in Google Docs.[2]

The Workspace post says what that rendered view is for. Drive can show the Markdown file with clickable links and structured tables, in Drive itself.[1] Use the preview when a teammate needs to read the draft. Use Docs when the comments have to live on the file.

## Open it, and look for the tag

The edit path on the new help page is short. Follow it as written.

- Upload the `.md` file to Google Drive.
- Click the `.md` file twice to open it in Google Docs.

It opens in Markdown Mode. You will find an `.md` tag next to the title. That tag is the check. If it is there, you are editing the Markdown file. You did not make a Doc.[2]

The help page's click instruction says `.md`. The product post also names `.markdown`. The pages I fetched do not give the longer extension its own click path. If an export tool handed you `.markdown`, save a copy as `.md` before you upload. That is the extension the click path names.[1][2]

There is no admin control for this feature, and no end-user setting to flip. The Workspace post says both, and it points end users at the help page rather than a preference.[1] You do not file a ticket to turn it on. You also cannot force it on for an account the rollout has not reached.

You can share the `.md` file from Google Docs. The help page says you can keep your comments and formatting when you reopen the document in Google Docs or in other tools.[2] Read that sentence next to the removal list on the same page. Formatting, on that page, does not include font color, highlight, or alignment.

The product post also says users and agents can collaborate in that editor without writing raw syntax, without a manual conversion, and without giving up comments.[1] That is Google's design claim. I did not run an agent through a shared file. Do not brief it as a result.

## Comment on the sentence, not the highlight

Some Docs features change when you edit an `.md` file. To get the earlier copy back, click File, then Version history.[2]

The removal list is short. Treat it as the limit, then comment on what the file can hold.

- Smart chips change to text or links.
- Web formatting, which the page writes as `.HTML`, turns into plain text.
- Docs removes font colors, highlights, and text alignment.[2]

If the review depends on a highlight or a centered line, that mark will not live in the Markdown file. Put the note in a comment. Comment on the heading, the claim, the link, the list. Those are the structures the Workspace post says Markdown keeps.[1]

The old conversion often stripped comments. The new path leaves the comment thread on the file you already uploaded.[1][2] Brand color and a centered line belong on the published page, after this review is done.

## Give the domains fifteen days

The pace line is specific, and it is easy to over-brief.

Rapid Release domains and Scheduled Release domains are on the same bullet. Gradual rollout, up to 15 days for feature visibility, starting on 5 October 2026.[1] Do not tell the Rapid Release team they have it this morning and the Scheduled Release team they have to wait. Google did not split them.

The availability line is wider. All Google Workspace customers, and users with personal Google accounts, are on it.[1] The pages I fetched do not give personal accounts a separate clock. The 15-day line is the one attached to those two domain tracks.

Available is not the same as visible this morning. If the double-click does not open Markdown Mode, or the `.md` tag is missing, you are still inside the window Google published. Wait. Check again before you convert the file to get a comment thread. Quote the rollout line if someone asks why it is not there yet.[1]

## Write the handoff before the tag shows up

You can write the handoff before the feature is visible. The file type is the point.

- Save the model draft as `.md`. Keep the headings, the lists, and the links in the file. Do not paste the draft into a blank Doc as the first move.
- Upload that file to Drive.[2]
- For a read-only pass, right-click it, choose Open with, then Preview, and switch between Markdown and Preview.[2] That rendered view is the one with clickable links and structured tables, once Drive's preview has reached the account.[1]
- For comments, click the file twice. Look for the `.md` tag next to the title. If the tag is there, the file type has not changed.[2]
- Share from Docs. Comment on the sentence. Leave the highlight color alone.[2]
- If someone applied a font color, a highlight, an alignment, a smart chip, or HTML formatting, expect those to change. File, then Version history, is the page's way back to the earlier copy.[2]
- When the comments are resolved, the file you hand to the site, the repo, or the next tool is still `.md`. You do not export it back out of a Doc to get there.

If the tag is missing, stop. You are either early in the rollout, or someone took the old import. Two paths on the older page still make a Doc. Inside Docs, that is File, Open, Upload. In Drive, that is Open with, Google Docs.[3] Paste from Markdown converts the clipboard the same way.[3] File, Download, Markdown (.md) exports that Doc as a new file. It is not the file you uploaded.[3] The new help page's point is that you never left the `.md` file.[2]

## What to tell the person doing the review

Give them four sentences. Three are on the new pages. The fourth is the clock.

The file stays `.md`. Click it twice, and look for the tag next to the title. Colors, highlights, and alignment will not stick, so put the note in a comment.[1][2] If they are on a company domain, there is nothing for an admin to switch on, and the feature can take up to 15 days from 5 October 2026 to show up.[1]

That is the whole lesson. An LLM draft can stay a Markdown file and still be reviewed with comments in Docs. Upload it. Click it twice. Leave the extension. If the `.md` tag is missing, you are still inside the window Google published. Check again before you convert the file.
