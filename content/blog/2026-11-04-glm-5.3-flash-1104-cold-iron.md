**By Nemo, SMF Works**

If you stood the 1104 Zig recipe and want the Cold Iron number, it is 77 out of 157. Zero errors. Every row has 0 reasoning tokens. That is this boot. The October write-up is a different serve, and it scored 113 out of 157. Do not paste those two totals into one rank.

Cold Iron is the thinking-off 157. It used to be called Official A. The machine id is still `strict_v01`.

## How to tell the files apart

Open `/v1/models` before you quote a score. This boot answers `GLM-5.3-Flash` on port 8020. The October file used `GLM-5.3-Flash-EXL3` on port 8888, checkout `3fd60df`, MTP drafts. Same family name. Different engine, different drafter, different id.

Then open the JSON and check three fields.

1. `thinking` is `off`.
2. `reasoning_tokens` is 0 on every row. This file has that on all 157.
3. Ignore `serve_recipe_id`. Ours says `SMF-Spark-vLLM-0.24-marlin`. That string is a stale process default. The process that answered is TensorFold Zig, image `tensorfold-glm53-spark:74e19a63a9a5`, native version 1.1.9.

If those three checks fail, you are looking at a different arm. Do not file it as Cold Iron.

## The score

One run. 77 passed, 80 failed, 0 errors. The file stores the pass rate as 49.0%. Wall time 3749 seconds. Finish reasons: 132 stop, 23 length, 2 tool calls. Cost in the JSON is 0. The endpoint does not bill.

Short prompts held up. Coding easy, medium, and hard were 2 of 2, 3 of 3, and 5 of 5. Frontier coding was 0 of 12. Thirteen coding fails are `SyntaxError`. Nineteen fails ended with `finish_reason` `length`, and ten of those are coding. The suite cap on those items is 4096 completion tokens. A length fail means the grader did not get a finished answer inside that cap. It does not, by itself, prove the model cannot write the program.

Writing missed `writing_creative` on keywords (2 of 5, need 3). Both tool calls passed: `get_weather` for Tokyo, and `calculate` for `45 * 73`.

## What to do with the number

Keep this file next to the tag above. Link the October post when you need the older pin, and say the engines differ. [The October 113](https://www.smfclearinghouse.com/blog/2026-10-18-glm-5.3-flash-cold-iron-same-113) is MTP on port 8888. This one is DFlash2 on port 8020.

Do not call a board rank from one run. A later true-off file on this same boot can move the ties. This post files the run. It does not reorder the board.
