# Jev 1.14

## What to call

The models page lists the id as `jev-1.14.0`. The October 14 blog also mentions `jev-preview` for the new release, and says `jev-latest` will be updated to `jev-1.14.0` in a week. That week lands on October 21. This card did not list live aliases, so don't assume the alias flipped because the calendar did.

`jev-1.13.0` stays available. The blog says they intend to give 60 days' warning before 1.13 is formally deprecated, and 30 days for 1.14. It also says a deprecation policy will come before that. Don't treat the intention as the policy.

## Price and the two context numbers

The models table prices Jev 1.14 at $42 per billion input tokens, which the same cell writes as $0.042 per million. Output tokens are free. You pay per input token.

Context is two limits, not one. Default per-request context is 64k. Default per-question context is 32k. The 64,000 in the frontmatter is the per-request default only. A single question still has to fit in 32k unless you opt in.

Long context is a header, `TypeSafe-Danger-Zone-Long-Context: true`, on each request that needs it. With the header, both limits are 262k tokens. The docs say this works on Jev 1.14 and Jev 1.13, costs the same per token, and is slower and less accurate than staying inside the default limits. Turn it on for the request that needs it. Leave it off for the rest.

The models page says Jev reads text: a string, a JSON object, or an array of text values. It does not accept audio or video. Images are a separate switch. See the guide `turn-on-jev-images`.

## What 1.14 adds, in their words

The October 14 post, "Jev: For the builders AND dreamers," says 1.14.0 is small improvements to everything, with the largest expected gain in multilingual support. It also turns on three experimental features:

- Images, off unless you send `TypeSafe-Danger-Zone-Images: true`. The blog says you can place them in `state`, `instructions`, or `criteria`.
- A `box` type that returns one bounding box. The blog says this type is enabled only for `jev-1.14.0`.
- Longer context, the header above.

The post's own warning is the header name: danger zone. The models page still lists input as text. If a client library hides the header, you are not on the image path.

Endpoint used by the images docs: `https://api.typesafe.ai/v1/systemone`. This card did not send a request.
